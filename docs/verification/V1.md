## Reference

Euler–Bernoulli: δ = F·L³ / (3·E·I), with I = b·h³/12 = 833.333 mm⁴, giving 0.2000 mm. Beam theory neglects shear deformation (Timoshenko adds ≈ 0.8 % here) and the 3D clamp also restrains Poisson contraction at the root, so a few tenths of a percent difference in either direction is physical, not numerical.
