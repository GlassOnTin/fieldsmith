## Method

1. **Grammar & validation (`fieldsmith-doc`)**: `fill <family> <mode> ... skin=<mm> skin_max=<mm>` parses and prints `skin_max` when present (`Option<f64>`), and `Document::validate()` plus `fill::check_spec()` require `skin_max.is_finite() && skin_max >= skin`.
2. **Field & GLSL (`fieldsmith-field`)**: `FillExpr` carries `skin_max: f64` and `param_range: [f64; 2]` (`[p_lo, p_hi]`). Both CPU evaluation (`FillExpr::eval`, `FillExpr::removed_skin`, `FillExpr::in_core`) and GLSL codegen (`glsl::generate`, `glsl::generate_viewport`) evaluate the local shell thickness as:
`skin(p) = skin + (skin_max - skin) * clamp((param(p) - p_lo) / (p_hi - p_lo), 0.0, 1.0)`.
When `skin_max <= skin`, GLSL emits the constant literal `lit(skin)`.
3. **Graded FEA coupling (`fieldsmith-core`)**: When `skin_max > skin`, the density blur includes populated boundary nodes and halos one radius outward so trilinear samples across the outer shell band interpolate local boundary von Mises stress without dropping toward `ρ_min`. Element material fractions `φ_e` are sampled directly from the resulting `FillExpr`, converting thickened root skin bands to full solid modulus (`φ → 1`).
