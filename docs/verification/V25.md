## Route (as executed)

1. **Cross-build on the referee.** `rustup target add aarch64-unknown-linux-musl`
   (rustc 1.97.1). The musl target self-contains its crt, but the default host `cc`
   cannot link aarch64 objects — the build sets
   `CC_aarch64_unknown_linux_musl=aarch64-linux-gnu-gcc` (cc-rs, ring's C objects),
   `AR_aarch64_unknown_linux_musl=aarch64-linux-gnu-ar`, and
   `CARGO_TARGET_AARCH64_UNKNOWN_LINUX_MUSL_LINKER=aarch64-linux-gnu-gcc`, then
   `cargo build -p fieldsmith-cli --release --target aarch64-unknown-linux-musl`:
   a 6.9 MB static aarch64 ELF, sha256
   `c51ba032bc86181f30b3d011b186f6ce44f58e77e9f73adf85d39efaecbadef6` on the referee,
   re-checked in the guest after transfer.
2. **Smoke before ship.** The same binary answered the pinned golden request under
   `qemu-aarch64` on the referee — its canon byte-ties the V22 fixture line (True).
   Component isolated where a re-run is cheap, before the phone carried it.
3. **Transfer.** The workstation served the binary over LAN HTTP; the guest `curl`ed
   it; sha256 matched in the guest. (Server stopped after.)
4. **Host.** Haven's proot guest (debian-trixie, glibc, arm64 rootfs) on the OnePlus 13
   (CPH2655, Android 16, SDK 36; `ro.soc.model` SM8750 — the costs.csv machine
   convention), 8 cores, 15.8 GB RAM, MemTotal 15469992 kB. The static binary runs
   bare. Every run with `FIELDSMITH_COSTS_STORE=/dev/null` — rows are hand-seeded,
   never auto-written.
5. **Pull-back.** The four envelopes returned over the MCP guest channel as base64 and
   md5-matched the guest-side bytes before any comparison ran.

  the ladders: rung-0 deflection 2.330609765727498 referee vs 2.330609765723763 phone,

  relative (rung-2 `change.deflection_mm` -0.06917596055294539 vs
  -0.06917596055520736).
- the sweep's change fields — small rung-to-rung estimates near 1e-4 — raw-diverge
  up to 7.165e-08 relative (4.502341966586276e-05 vs 4.5023416439915476e-05, a 3.2e-12
  absolute gap, at point 11 mm). Small numbers make the relative measure look large;
  the absolute gap stays at the 1e-12 scale.

The **canon quantization** (each float to 6 significant digits — the V22 transform)
ties every one of the 259 scalars, including those 94.
