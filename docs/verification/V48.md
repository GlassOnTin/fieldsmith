## Method and coupon protocol

Each TPMS class (`gyroid`, `primitive`, `diamond` in `sheet` and `network` modes) was meshed and solved on an `N = 3` unit-cell cube (`cell = 2.0 mm`, `E_s = 1000 MPa`, `ν = 0.3`, `h = t` for sheets and `h = R` for networks) across `ρ ∈ {0.2, 0.3, 0.4}` using `fieldsmith_verify::coupon::run`. On the 1-cell interior strain band, Hill–Mandel energy equivalence gives `Σ / σ_eq,rms = √(ρ_mesh · E*_int / E_s)`, which combines with the interior 95th-percentile concentration factors `vm_int_p95 / vm_int_rms` and `comp_int_p95 / vm_int_rms` and the resolved feature slenderness `(feature / cell)²` to determine `yield_ratio` and `buckling_ratio`.
